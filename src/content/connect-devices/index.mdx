# Connect Devices

Register your IoT devices in minutes using our Library for Arduino IDE. IoTDataHub supports **Arduino**, **ESP32**, **Raspberry Pi**, and any HTTP-capable hardware — no DevOps expertise required.

## In this section

| Guide | Description |
| ----- | ----------- |
| [Supported Hardware](/connect-devices/supported-hardware) | Platforms, connections, and integration methods |
| [Arduino Library](/connect-devices/arduino-library) | Install and use the IoTDataHub library in Arduino IDE |
| [REST API](/connect-devices/rest-api) | Send data from any HTTP-capable device |

## Quick start

1. Create a [channel](/data-channels/channels) and copy your Write API Key.
2. Install the [Arduino library](/connect-devices/arduino-library) or use the [REST API](/connect-devices/rest-api).
3. Confirm readings appear in your IoTDataHub dashboard within seconds.

New here? Begin with [Getting Started](/getting-started).
