# Arduino Library

The IoTDataHub library for Arduino IDE connects your microcontroller to the cloud and syncs widget states with your online control panel.

## Installation

1. Open Arduino IDE
2. Go to **Sketch → Include Library → Manage Libraries**
3. Search for **IoTDataHub**
4. Click **Install**

## Device configuration

Before writing code, complete the platform setup in [Getting Started](/getting-started):

1. Create a [channel](/data-channels/channels)
2. Register a [device](/getting-started#3-register-a-device) from that channel
3. Build your [Widget Box](/dashboards/widgets)
4. Click **Config** on your device page to open **Device Configuration**

You need four values from this dialog:

| Credential | Description |
| ---------- | ----------- |
| `IOTDATAHUB_USER_NAME` | Your account name |
| `IOTDATAHUB_ORGANIZATION_NAME` | Your workspace name |
| `IOTDATAHUB_DEVICE_TOKEN` | Secret token that authenticates your device |
| `IOTDATAHUB_DEVICE_ID` | Unique identifier for this device |

Keep your device token private — treat it like a password.

## Basic sketch

Paste your credentials and WiFi settings into this template. The library reads the `#define` values automatically — paste them exactly as shown in the Config dialog.

```cpp
#include <IoTDataHub.h>

// Paste from Device Configuration (Config button)
#define IOTDATAHUB_USER_NAME         "Your Name"
#define IOTDATAHUB_ORGANIZATION_NAME "My Work Space"
#define IOTDATAHUB_DEVICE_TOKEN      "your-device-token"
#define IOTDATAHUB_DEVICE_ID         "your-device-id"

// Your WiFi network — must match your actual network
const char* ssid     = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";

IoTDataHub iot;

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  iot.begin();
}

void loop() {
  iot.run(); // Keeps the device connected and syncs widget states
}
```

Upload the sketch to your microcontroller. Once connected, your device page shows an **online** indicator and your widgets become interactive.

## Virtual pins

Each widget on your control panel maps to a **virtual pin** on your microcontroller. When you configured widgets in the Widget Box, you assigned datastreams (virtual pins) to each one. Your sketch reads and writes these pins to sync with the dashboard.

For example, a Switch widget on virtual pin `V0` with on value `1` and off value `0` controls a GPIO pin on your board.

## Troubleshooting

- **Device stays offline?** Double-check your WiFi name and password, and verify all four configuration values are pasted correctly.
- **Widgets not responding?** Confirm virtual pin numbers in your sketch match the datastreams you configured in the Widget Box.
- **Wi-Fi issues on ESP32?** Ensure `WiFi.begin()` completes before calling `iot.begin()`.
