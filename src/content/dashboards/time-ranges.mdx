# Time Ranges & Export

Slice historical data by time range and export reports in one click.

## Time range filters

Filter any chart or dashboard by:

- Last hour / 24 hours / 7 days / 30 days
- Custom date range
- Real-time (live updating)

Real-time mode keeps your dashboard live as new [streamed data](/data-channels/streaming) arrives from connected devices.

## Exporting data

Click **Export** on any chart to:

- Download data as **CSV** for spreadsheet analysis
- Generate a **PDF report** for sharing or archiving

Exports include all data visible within the selected time range.

## Use cases

- **Weekly reports** — export 7-day energy consumption as CSV
- **Compliance** — generate PDF snapshots of environmental readings
- **Analysis** — pull raw data into Python, Excel, or BI tools
