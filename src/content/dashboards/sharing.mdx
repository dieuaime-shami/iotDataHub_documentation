# Sharing Dashboards

Share read-only dashboard links with your team or embed charts in external applications.

## Public dashboard URL

Each dashboard can generate a **public read-only link**. Anyone with the link can view live data without an IoTDataHub account.

To share:

1. Open your dashboard in IoTDataHub
2. Click **Share** or copy the public dashboard URL
3. Send the link to teammates, clients, or stakeholders

## Embedding

Use the public dashboard URL to embed charts in:

- Internal wikis or intranet pages
- Client-facing portals
- Operations center displays

Shared dashboards reflect real-time data from your [channels](/data-channels/channels) — updates appear automatically as devices send new readings.

## Security note

Public links are read-only. Viewers cannot modify alerts, change channel settings, or access your Write API Keys.
