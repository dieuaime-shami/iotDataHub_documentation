# Data & Channels

Channels are the foundation of IoTDataHub — they define your hardware platform, connection type, and the data path between your devices and the cloud.

## In this section

| Guide | Description |
| ----- | ----------- |
| [Channels](/data-channels/channels) | Create channels and configure hardware settings |
| [Streaming Data](/data-channels/streaming) | Send readings and monitor live updates |
| [Field Limits & Plans](/data-channels/field-limits) | Fields per channel and update rates |

## How it fits together

```
Channel  →  Device  →  Widget Box  →  Arduino Sketch  →  Online Control
```

1. A **channel** defines your hardware and connection type.
2. A **device** is registered from that channel and gets its own control panel.
3. The **Widget Box** maps virtual pins to your physical hardware.
4. Your **Arduino sketch** uses device configuration credentials to connect.

Already connected a device? Jump to [Streaming Data](/data-channels/streaming).
