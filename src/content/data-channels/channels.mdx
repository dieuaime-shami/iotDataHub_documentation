# Channels

Channels are the first step in connecting hardware to IoTDataHub. Each channel defines your **hardware platform**, **connection type**, and the data path between your microcontroller and the cloud.

## Create a channel

1. Sign in to [IoTDataHub](https://www.iotdatahub.rw/)
2. Open **Channels** in the sidebar
3. Click **+ Add New Channel**

### Channel fields

| Field | Description |
| ----- | ----------- |
| **Channel Name** | A unique, descriptive name (e.g. `temperature-sensors`, `blinking`) |
| **Hardware** | Your microcontroller — ESP32, ESP8266, Arduino, Raspberry Pi, or Other |
| **Connection Type** | How the device connects — WiFi, Ethernet, Satellite, or GSM |
| **Description** | Optional notes about the channel (up to 128 characters) |

## After creating a channel

Once saved, your channel appears in the list. The next step is to [register a device](/getting-started#3-register-a-device) linked to that channel.

```
Channel  →  Device  →  Widget Box  →  Arduino Sketch
```

## Naming conventions

Use clear, consistent names across channels and devices:

| Good | Avoid |
| ---- | ----- |
| `temperature-sensors` | `ch1`, `test`, `abc` |
| `energy-monitor` | `data`, `temp1` |
| `blinking-led` | `x`, `field3` |

Consistent naming makes [dashboards](/dashboards) and [alerts](/alerts) easier to configure.

## Multiple devices, one channel

You can register multiple devices from the same channel. Each device gets its own control panel and configuration credentials.
