# Channels

Channels are the core storage unit in IoTDataHub — each channel holds up to 8 fields of sensor data from one or more devices.

## Create a channel

1. Sign in to [IoTDataHub](https://www.iotdatahub.rw/)
2. Go to **Channels** and click **New Channel**
3. Give it a descriptive name (e.g. `temperature-sensors`, `energy-monitor`)
4. Copy your **Write API Key** — you'll need this in your device code

## Write API Key

The Write API Key authorizes your device to push data to a specific channel. Keep it private and treat it like a password.

Use the key in your [Arduino library](/connect-devices/arduino-library) or [REST API](/connect-devices/rest-api) calls:

```cpp
IoTDataHub iot("YOUR_WRITE_API_KEY");
```

## Naming conventions

Use clear, consistent field names across devices:

| Good | Avoid |
| ---- | ----- |
| `temperature` | `temp1`, `t`, `field3` |
| `humidity` | `data`, `val` |
| `power_kw` | `x` |

Consistent naming makes [dashboards](/dashboards) and [alerts](/alerts) easier to configure.

## Multiple devices, one channel

You can send data from multiple devices to the same channel as long as they use the same Write API Key and field names.
