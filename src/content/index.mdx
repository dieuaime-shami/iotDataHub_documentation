# Welcome to IoTDataHub Docs

**IoTDataHub** is a cloud platform for connecting IoT devices, streaming sensor data, and building interactive analytics dashboards — simple by design.

> Connecting devices, analyzing data, enabling smart decisions.

## What you can do

- **Connect devices** — Register Arduino, ESP32, Raspberry Pi, and any HTTP-capable hardware in minutes using our Arduino IDE library.
- **Stream data** — Push sensor readings, events, and telemetry to your channels in real time with encrypted transit.
- **Visualize & analyze** — Build dashboards with line charts, gauges, and bar graphs. Export reports in one click.
- **Act on alerts** — Receive notifications via email, SMS, or webhook and trigger automated device actions.
