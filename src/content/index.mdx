# Welcome to IoTDataHub Docs

**IoTDataHub** is a cloud platform for connecting IoT devices, streaming sensor data, and building interactive analytics dashboards — **simple by design**.

> Connecting devices, analyzing data, enabling smart decisions.

## How IoTDataHub works

From hardware to insight in four straightforward steps — no DevOps expertise required.

| Step | Guide | Description |
| ---- | ----- | ----------- |
| 01 | [Connect Devices](/connect-devices) | Register Arduino, ESP32, Raspberry Pi, and HTTP hardware |
| 02 | [Data & Channels](/data-channels) | Stream sensor data to the cloud in real time |
| 03 | [Dashboards](/dashboards) | Visualize with charts, gauges, and bar graphs |
| 04 | [Alerts & Automation](/alerts) | Email, SMS, and webhook notifications |
