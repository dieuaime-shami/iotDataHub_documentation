# Connect Devices

Register your IoT devices in minutes using our Library for Arduino IDE. IoTDataHub supports Arduino, ESP32, Raspberry Pi, and any HTTP-capable hardware.

## Supported hardware

| Platform | Connection | Library |
| -------- | ---------- | ------- |
| ESP32 / ESP8266 | Wi-Fi | IoTDataHub Arduino Library |
| Arduino + Ethernet shield | Ethernet | IoTDataHub Arduino Library |
| Raspberry Pi | HTTP REST | Python `requests` or curl |
| Any HTTP device | REST API | Direct HTTP POST |

## Arduino IDE library

### Installation

```
Sketch → Include Library → Manage Libraries → Search "IoTDataHub" → Install
```

### Basic usage

```cpp
#include <IoTDataHub.h>

IoTDataHub iot("YOUR_WRITE_API_KEY");

void setup() {
  iot.begin();
}

void loop() {
  iot.writeField("field1", analogRead(A0));
  iot.writeField("field2", 42);
  delay(20000); // Minimum 15 seconds between updates on free tier
}
```

## HTTP REST API

Send data from any device that can make HTTP requests:

```bash
curl "https://api.iotdatahub.rw/update?api_key=YOUR_KEY&field1=25.4&field2=60"
```

## Field limits

| Plan | Fields per channel | Update rate |
| ---- | ------------------ | ----------- |
| Free | 8 fields | 15 sec minimum |
| Pro | 8 fields | 1 sec minimum |

## Troubleshooting

- **No data appearing?** Verify your Write API Key and channel name.
- **Rate limit errors?** Wait at least 15 seconds between updates on the free tier.
- **Wi-Fi issues on ESP32?** Ensure `WiFi.begin()` completes before calling `iot.begin()`.
