# Dashboard & Analytics

Build interactive dashboards with line charts, gauges, and bar graphs. Slice historical data by time range and export reports in one click.

## Creating a dashboard

1. Navigate to **Dashboards** in your IoTDataHub account
2. Click **New Dashboard** and choose a template or start blank
3. Add widgets by selecting your channels and fields

## Widget types

| Widget | Best for |
| ------ | -------- |
| **Line chart** | Temperature, humidity, and trends over time |
| **Gauge** | Current values with min/max thresholds |
| **Bar chart** | Comparing readings across time periods |
| **Number** | Single latest value display |
| **Map** | Geo-located sensor data |

## Time ranges

Filter historical data by:

- Last hour / 24 hours / 7 days / 30 days
- Custom date range
- Real-time (live updating)

## Exporting data

Click **Export** on any chart to download data as CSV or generate a PDF report.

## Dashboard sharing

Share read-only dashboard links with your team or embed charts in external applications using the public dashboard URL.

## Tips

- Group related sensors on one dashboard for easier monitoring
- Use consistent field naming across channels for cleaner charts
- Set up [Smart Alerts](/alerts) alongside dashboards for proactive monitoring
